# Dr. Alcofree - Natural Alcohol Recovery Platform

## Project Overview
Dr. Alcofree is a React-based web application focused on natural alcohol recovery solutions using Ayurvedic and herbal approaches. The platform provides information, products, and support for individuals seeking to overcome alcohol addiction through natural methods.

## Technology Stack
- **Frontend**: React 18.3.1
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Build Tool**: Create React App
- **Language**: JavaScript (ES6+)

## Project Structure
```
src/
├── components/          # Reusable UI components
├── pages/              # Page components
├── schemas/            # Data validation schemas
├── assets/             # Images, fonts, static files
├── utils/              # Utility functions
└── styles/             # CSS and styling files

public/
├── sitemap/            # SEO sitemap files
├── favicon.ico         # Site icon

├── product.schema.js   # Product data validation
├── user.schema.js      # User/customer data
├── order.schema.js     # Order processing
├── testimonial.schema.js # Success stories
├── common.schema.js    # Shared structures
└── index.js           # Schema exports & config
```

## Schema System
The project uses a comprehensive schema system for data validation:

### Recovery-Specific Data Structures
- **Recovery Stages**: considering, just_started, in_progress, maintaining, supporting_others
- **Alcohol Usage Patterns**: daily, weekly, occasionally, heavy, stopped
